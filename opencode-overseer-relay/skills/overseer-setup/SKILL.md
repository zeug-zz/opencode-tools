# Overseer campaign setup

Use this skill only to plan and prepare an explicitly requested two-worker A/B
campaign. Follow the detailed, project-neutral procedure in
[the setup checklist](references/setup-checklist.md).

Confirm the effective skill version and the exact actions with the owner before
making changes. Preparation approval never implies relay activation. Phase 1 is
Overseer notices only; worker delivery, steers, pauses, and goal-resume controls
are not implemented here.
